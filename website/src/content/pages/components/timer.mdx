### Countdown

Set `countdown` to `true` and `startMs` to the initial time.

<Example id="countdown" />

### Interval

`interval` sets how often the timer updates. Lower it to display milliseconds.

<Example id="interval" />

### Events

- `onComplete` fires when the timer reaches its target time.
- `onTick` fires on each update with the current timer state.

<Example id="events" />
