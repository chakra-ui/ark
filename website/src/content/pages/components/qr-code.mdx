### Error Correction

Raise the error correction level when the link is long or the overlay covers much of the code. Set it with
`encoding.ecc` or `encoding.boostEcc`:

- `L`: recovers up to 7% data loss (default)
- `M`: up to 15%
- `Q`: up to 25%
- `H`: up to 30%

<Example id="error-correction" />
