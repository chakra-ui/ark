## Guides

### Content Animation

Marquee needs CSS keyframes for horizontal and vertical scrolling:

```css
@keyframes marqueeX {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(var(--marquee-translate));
  }
}

@keyframes marqueeY {
  from {
    transform: translateY(0);
  }
  to {
    transform: translateY(var(--marquee-translate));
  }
}
```

The component applies `marqueeX` or `marqueeY` based on direction and uses `--marquee-translate` to loop without a jump.

Style parts through their data attributes:

- `[data-marquee-root]` - The root container
- `[data-marquee-viewport]` - The scrolling viewport
- `[data-marquee-content]` - The content wrapper (receives animation)
- `[data-marquee-item]` - Individual marquee items
- `[data-marquee-edge]` - Edge gradient overlays

### Best Practices

- **Enable pause-on-interaction**: Set `pauseOnInteraction` so users can pause on hover or focus.
- **Use descriptive labels**: Give an `aria-label` that names the content (e.g., "Partner logos").
- **Avoid for critical information**: Moving text is hard to read. Show essential content statically.
