## Anatomy

<Anatomy id="carousel" />

```tsx
<Carousel.Root>
  <Carousel.Control>
    <Carousel.PrevTrigger />
    <Carousel.NextTrigger />
  </Carousel.Control>
  <Carousel.ItemGroup>
    <Carousel.Item />
  </Carousel.ItemGroup>
  <Carousel.IndicatorGroup>
    <Carousel.Indicator />
  </Carousel.IndicatorGroup>
</Carousel.Root>
```

## Examples

<Example id="basic" />

### Controlled

Use `page` and `onPageChange` to control the current page.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useCarousel` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Autoplay

Set `autoplay` and `loop` on `Carousel.Root` to play the slides automatically.

<Example id="autoplay" />

### Pause on Hover

Pause on hover isn't built in. Call `play()` and `pause()` from `Carousel.Context` to add it.

<Example id="pause-on-hover" />

### Thumbnail Indicators

Render an image thumbnail inside each `Carousel.Indicator` in place of the default dots.

<Example id="thumbnail-indicator" />

### Vertical

Set `orientation="vertical"` on `Carousel.Root` to scroll vertically.

<Example id="vertical" />

### Dynamic

Store slides in state and keep the page in sync. Pass `page` and `onPageChange` to `Carousel.Root`, and update
`slideCount` when slides are added or removed.

<Example id="dynamic-slides" />

### Scroll to Slide

Call `api.scrollToIndex(index)` from `Carousel.Context` to jump to a specific slide.

<Example id="scroll-to" />

### Slides Per Page

Set `slidesPerPage` on `Carousel.Root` to show several slides at once. Render indicators from `api.pageSnapPoints` so
there is one per page, not per slide. Use `spacing` to set the gap.

<Example id="slides-per-page" />

### Spacing

Set `spacing` on `Carousel.Root` to control the gap between slides. Combine it with `slidesPerPage` to show partial
previews of adjacent slides.

<Example id="spacing" />

### Variable Sizes

Set `autoSize` on `Carousel.Root` so each `Carousel.Item` can define its own width. Use `snapAlign` on an item to
control where it snaps into view.

<Example id="variable-size" />
