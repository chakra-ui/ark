### Root Provider

Use `RootProvider` with the `useTreeView` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Lazy Loading

Load a node's children on demand to cut initial load time and memory use. Provide:

- `loadChildren`: loads the children of a node.
- `onLoadChildrenComplete`: called when children finish loading. Update the tree collection here.
- `childrenCount`: the number of children of a branch node.

<Example id="async-loading" />

### Lazy Mount

Set `lazyMount` on `TreeView.Root` to render branch content only when it's expanded. This helps when content is large.

Add `unmountOnExit` to unmount content when a branch collapses. It re-renders the next time the branch expands.

<Example id="lazy-mount" />

### Filtering

Combine the collection's `filter` method with the `useFilter` hook to show only nodes that match a search query.

<Example id="filtering" />

### Links

Render tree items as links, for example in a docs site. Store a link hierarchy in the collection and use `asChild` to
render each item as an `<a>` with an `href`.

<Example id="links" />

### Virtualized

For trees with thousands of nodes, render only the visible rows with the [Virtualizer](/docs/utilities/virtualizer).

- Use `useTreeView` with `TreeView.RootProvider`.
- `getVisibleNodes()` returns the flat list of visible nodes. Keep the virtualizer's `count` in sync with it.
- Render `TreeView.Tree` as `ListVirtualizer.Root` and each `TreeView.Node` as `ListVirtualizer.Item`.
- Pass `scrollToIndexFn` to enable keyboard navigation.

<Example id="virtualized" />

### Checkbox Tree

Set `defaultCheckedValue` to enable checkbox selection. Checking a parent or child updates the related nodes.

<Example id="checkbox-tree" />

### Expand and Collapse All

Call `expand()` or `collapse()` from the tree view context to toggle all branches.

<Example id="expand-collapse-all" />

### Mutation

Use the collection's `remove()` and `replace()` methods to add and remove nodes, for example in a file explorer.

<Example id="mutation" />

### Rename Node

Use `canRename` and `onRenameComplete` for inline renaming. Press <kbd>F2</kbd> to rename the focused node.

<Example id="rename-node" />

## Guides

### Type Safety

Use the `TreeView.RootComponent` type to build wrappers that keep tree nodes fully typed.

```tsx
import { TreeView as ArkTreeView } from '@ark-ui/react/tree-view'

const TreeView: ArkTreeView.RootComponent = (props) => {
  return <ArkTreeView.Root {...props}>{/* ... */}</ArkTreeView.Root>
}
```

`onSelectionChange` and other callbacks then infer the node type:

```tsx
const App = () => {
  const collection = createTreeCollection({
    initialItems: [
      { id: '1', label: 'React', children: [] },
      { id: '2', label: 'Vue', children: [] },
    ],
  })
  return (
    <TreeView
      collection={collection}
      onSelectionChange={(e) => {
        // e.items is typed as Array<{ id: string, label: string, children: [] }>
        console.log(e.items)
      }}
    >
      {/* ... */}
    </TreeView>
  )
}
```
