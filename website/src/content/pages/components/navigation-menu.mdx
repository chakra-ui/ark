## Examples

<Example id="basic" />

### Viewport

Use `NavigationMenu.Viewport` for one shared panel. Add `NavigationMenu.Indicator` so the arrow tracks the open trigger.

<Example id="viewport" />

### Current link

Set `current` on the link for the current page. It renders `aria-current="page"` and a `data-current` attribute for
styling.

<Example id="current-link" />

### Vertical

Set `orientation="vertical"` for sidebar navigation. Panels open to the side. ArrowUp and ArrowDown move between
triggers, and ArrowRight enters the open panel.

<Example id="vertical" />

### Indicator

Render `NavigationMenu.Indicator` inside the list to highlight the active trigger, tab-style. It slides between triggers
with a CSS transition on `--trigger-x` and `--trigger-width`. For a static per-item marker, use
`NavigationMenu.ItemIndicator`.

<Example id="indicator" />

### Controlled

Use `value` and `onValueChange` to control the active item.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useNavigationMenu` hook to access the state and methods from outside the component.

<Example id="root-provider" />

## Guides

### Custom links

Use `asChild` to render `NavigationMenu.Link` as your router's link component.

```tsx
import { Link as RouterLink } from 'react-router-dom'
import { NavigationMenu } from '@ark-ui/<framework>/navigation-menu'

export const MenuLink = (props: NavigationMenu.LinkProps) => {
  return (
    <NavigationMenu.Link {...props} asChild>
      <RouterLink to={props.href ?? '#'}>{props.children}</RouterLink>
    </NavigationMenu.Link>
  )
}
```

<FrameworkOnly framework="web">

In `@ark-ui/web`, `ark-navigation-menu-link` wraps your `a` element and applies the link props to it. Mark the current
page with `current`. For client-side routing, intercept the anchor's click:

```html
<ark-navigation-menu-link current><a href="/docs">Documentation</a></ark-navigation-menu-link>
```

</FrameworkOnly>

### Viewport size

`NavigationMenu.Root` and `NavigationMenu.Viewport` expose these CSS variables:

```css
/* size and position of the active trigger */
--trigger-width: <pixel-value>;
--trigger-height: <pixel-value>;
--trigger-x: <pixel-value>;
--trigger-y: <pixel-value>;

/* size and position of the active content */
--viewport-width: <pixel-value>;
--viewport-height: <pixel-value>;
--viewport-x: <pixel-value>;
--viewport-y: <pixel-value>;
```

Animate the shared panel between items with `--viewport-width` and `--viewport-height`:

```css
[data-navigation-menu-viewport] {
  width: var(--viewport-width);
  height: var(--viewport-height);
  transition:
    width 250ms ease,
    height 250ms ease;
}
```

### Large menus

For content taller than the viewport, cap the panel and scroll the content:

```css
[data-navigation-menu-viewport] {
  max-height: min(var(--viewport-height), 70vh);
}

[data-navigation-menu-content] {
  max-height: 70vh;
  overflow-y: auto;
}
```
