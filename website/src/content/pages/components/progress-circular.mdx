## Examples

<Example id="basic" />

### Min and Max

Set `min` and `max` to change the range. The default max is `100`. This example shows progress from `10` to `30`.

<Example id="min-max" />

### Indeterminate

Progress is determinate by default, with `value` 50 and `max` 100. Set `value` to `null` for indeterminate progress.

<Example id="indeterminate" />

## Guides

### Styling the Circle

Set these CSS variables on `Progress.Circle` to control its size and thickness:

```css
[data-progress-circle] {
  --size: 120px;
  --thickness: 10px;
}
```

| Variable      | Description                          |
| ------------- | ------------------------------------ |
| `--size`      | The width and height of the circle   |
| `--thickness` | The stroke width of the circle track |
