## Guides

### Scrubber

`NumberInput.Scrubber` is a `<div>` users drag to change the value. It shows a custom cursor while scrubbing and uses
the [Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API).

> **Note:** Browsers may show a notification when pointer lock activates. The scrubber is disabled in Safari to prevent
> layout shifts.

### Controlled

Keep the controlled value as a string, not a number. This matters most with `formatOptions` for currency or locales.

```tsx
const [value, setValue] = useState('0')

<NumberInput.Root value={value} onValueChange={(details) => setValue(details.value)}>
  {/* ... */}
</NumberInput.Root>
```

Converting to numbers breaks locale formats with different decimal and thousands separators (e.g., `1.523,30` vs
`1,523.30`). Strings keep the formatting intact.

To submit a numeric value, add a hidden input that reads `value` from `NumberInput.Context`:

```tsx
<NumberInput.Root value={value} onValueChange={(details) => setValue(details.value)}>
  <NumberInput.Input />
  <NumberInput.Context>
    {(context) => <input type="hidden" name="amount" value={context.value ?? ''} />}
  </NumberInput.Context>
</NumberInput.Root>
```
