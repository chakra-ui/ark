### Disabled

Set `disabled` to stop the collapsible from toggling.

<Example id="disabled" />

### Partial Collapse

Set `collapsedHeight` or `collapsedWidth` for a "show more/less" pattern. The content keeps that size when collapsed
instead of shrinking to 0px. Use the `--collapsed-height` or `--collapsed-width` variables in your CSS animations.

<Example id="partial-collapse" />

> Interactive elements in the collapsed area become `inert`, so keyboard users can't reach hidden content.

### Nested Collapsibles

### Lazy Mount

Set `lazyMount` to mount the content on first open and `unmountOnExit` to remove it on collapse. With both, the content
is in the DOM only while expanded.

## Guides

### Indicator Animation

Rotate the indicator on open with the `data-state` attribute:

```css
[data-collapsible-indicator] {
  transition: transform 200ms;

  &[data-state='open'] {
    transform: rotate(180deg);
  }
}
```

### Open vs Visible

`useCollapsible` and `useCollapsibleContext` expose both `open` and `visible`.

- **`open`**: the intended state. It changes as soon as the collapsible is toggled.
- **`visible`**: whether the content is shown. It stays `true` while the exit animation plays, even though `open` is
  already `false`, and turns `false` when the animation ends.

### Content Animation

Animate the content size with the `--height` and `--width` CSS variables. With `collapsedHeight` or `collapsedWidth`,
use `--collapsed-height` or `--collapsed-width` as the start and end point:

```css
@keyframes expand {
  from {
    height: var(--collapsed-height, 0);
  }
  to {
    height: var(--height);
  }
}

@keyframes collapse {
  from {
    height: var(--height);
  }
  to {
    height: var(--collapsed-height, 0);
  }
}

[data-collapsible-content] {
  &[data-state='open'] {
    animation: expand 250ms;
  }
  &[data-state='closed'] {
    animation: collapse 250ms;
  }
}
```
