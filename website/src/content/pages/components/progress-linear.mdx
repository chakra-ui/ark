## Examples

<Example id="basic" />

### Min and Max

Set `min` and `max` to change the range. The default max is `100`. This example shows progress from `10` to `30`.

<Example id="min-max" />

### Indeterminate

Progress is determinate by default, with `value` 50 and `max` 100. Set `value` to `null` for indeterminate progress.

<Example id="indeterminate" />

### Value Text

Only sighted users can read a progress bar. Set the `value` key in `translations` to give screen readers a text
description.

<Example id="value-text" />

### Orientation

Set `orientation="vertical"` for a vertical progress.

> Give the vertical progress a height in your styles.

<Example id="vertical" />

### Root Provider

Use `RootProvider` with the `useProgress` hook to access the state and methods from outside the component.

<Example id="root-provider" />
