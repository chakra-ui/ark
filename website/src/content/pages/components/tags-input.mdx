## Anatomy

<Anatomy id="tags-input" />

```tsx
<TagsInput.Root>
  <TagsInput.Label />
  <TagsInput.Control>
    <TagsInput.Item>
      <TagsInput.ItemPreview>
        <TagsInput.ItemText />
        <TagsInput.ItemDeleteTrigger />
      </TagsInput.ItemPreview>
      <TagsInput.ItemInput />
    </TagsInput.Item>
    <TagsInput.Input />
    <TagsInput.ClearTrigger />
  </TagsInput.Control>
  <TagsInput.HiddenInput />
</TagsInput.Root>
```

## Examples

<Example id="basic" />

### Controlled

Pass `value` and update it in `onValueChange` to manage the tags array yourself.

<Example id="controlled" />

### Controlled Input Value

Use `inputValue` and `onInputValueChange` to control the text field on its own, for example to clear or pre-fill it.

<Example id="controlled-input-value" />

### Root Provider

Use `RootProvider` with the `useTagsInput` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Field

Wrap the tags input in `Field` to wire up the label, helper text, error text and ARIA attributes.

<Example id="with-field" />

### Max Tags

Set `max` to limit the number of tags (default `Infinity`). Once the limit is reached, new tags are rejected unless
`allowOverflow` is `true`.

<Example id="max-with-overflow" />

### Custom Delimiter

Pass a regex to `delimiter` to split tags on several characters. By default, only Enter creates a tag.

<Example id="delimiter" />

### Disabled

Set `disabled` to block adding, removing and editing tags.

<Example id="disabled" />

### Invalid

Set `invalid` to mark the tags input as invalid.

<Example id="invalid" />

### Max Length

Set `maxLength` to cap the characters per tag.

<Example id="max-tag-length" />

### Read-only

Set `readOnly` to show tags without allowing changes.

<Example id="readonly" />

### Validation

`validate` runs before a tag is added and decides whether to accept it. Use it to prevent duplicates or check the data
type.

<Example id="validation" />

### Blur behavior

`blurBehavior` sets what happens when the input loses focus:

- `add`: Adds the tag to the list of tags.
- `clear`: Clears the tags input value.

<Example id="blur-behavior" />

### Paste behavior

Set `addOnPaste` to add tags from pasted text. The pasted value is:

- checked against `validate`
- split by `delimiter`

<Example id="paste-behavior" />

### Disable Editing

Tags are editable by default: double-click a tag, or focus it and press <kbd>Enter</kbd>. Pass `editable={false}` to
turn this off.

<Example id="disabled-editing" />

### Programmatic Control

Use `useTagsInput` with `RootProvider` to call API methods like `addValue()`, `setValue()` and `clearValue()`.

<Example id="programmatic-control" />

### Sanitize Value

`sanitizeValue` normalizes every new tag before it's added, for example to trim whitespace or lowercase it.

<Example id="sanitize-value" />

### Combobox

Combine TagsInput with Combobox for autocomplete. Share IDs between both components and compose the inputs with
`asChild`.

<Example id="with-combobox" />

## Guides

### Navigation

When the input is empty or the caret is at the start, use the left and right arrow keys to move through tags. When a tag
has visual focus:

- <kbd>Enter</kbd> or double-click puts it in edit mode. Press <kbd>Enter</kbd> again to commit.
- <kbd>Delete</kbd> or <kbd>Backspace</kbd> deletes it.
