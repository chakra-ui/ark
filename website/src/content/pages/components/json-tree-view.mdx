### Configuration Options

These props customize the display:

```tsx
<JsonTreeView.Root
  data={data}
  defaultExpandedDepth={2}
  quotesOnKeys={true}
  showNonenumerable={true}
  maxPreviewItems={5}
  collapseStringsAfterLength={50}
  groupArraysAfterLength={100}
>
  <JsonTreeView.Tree arrow={<ChevronRightIcon />} />
</JsonTreeView.Root>
```

**Configuration Options:**

- **`quotesOnKeys`**: show quotes around object keys
- **`showNonenumerable`**: show non-enumerable properties
- **`maxPreviewItems`**: max items in object/array previews
- **`collapseStringsAfterLength`**: collapse strings longer than this
- **`groupArraysAfterLength`**: group items of arrays longer than this
