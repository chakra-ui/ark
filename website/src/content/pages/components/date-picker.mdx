## Anatomy

<Anatomy id="date-picker" />

```tsx
<DatePicker.Root>
  <DatePicker.Label />
  <DatePicker.Control>
    <DatePicker.Input />
    <DatePicker.Trigger />
    <DatePicker.ClearTrigger />
  </DatePicker.Control>
  <DatePicker.Positioner>
    <DatePicker.Content>
      <DatePicker.View>
        <DatePicker.ViewControl>
          <DatePicker.PrevTrigger />
          <DatePicker.ViewTrigger>
            <DatePicker.RangeText />
          </DatePicker.ViewTrigger>
          <DatePicker.NextTrigger />
        </DatePicker.ViewControl>
        <DatePicker.Table>
          <DatePicker.TableHead>
            <DatePicker.TableRow>
              <DatePicker.TableHeader />
            </DatePicker.TableRow>
          </DatePicker.TableHead>
          <DatePicker.TableBody>
            <DatePicker.TableRow>
              <DatePicker.TableCell>
                <DatePicker.TableCellTrigger />
              </DatePicker.TableCell>
            </DatePicker.TableRow>
          </DatePicker.TableBody>
        </DatePicker.Table>
      </DatePicker.View>
    </DatePicker.Content>
  </DatePicker.Positioner>
</DatePicker.Root>
```

## Examples

<Example id="basic" />

### Default Value

Use `defaultValue` with `parseDate` to set the initial date.

<Example id="default-value" />

### Controlled

Use `value` and `onValueChange` to control the value.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useDatePicker` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Default View

Set `defaultView` to open the calendar on the day, month, or year view.

<Example id="default-view" />

### Month and Year Select

Use `MonthSelect` and `YearSelect` next to the prev/next triggers for dropdown month and year navigation.

<Example id="month-year-select" />

### Range

Set `selectionMode="range"` and render two inputs with `index` set to `0` and `1`.

<Example id="range-selection" />

### Multiple

Set `selectionMode="multiple"` to select several dates. This example shows them as removable tags.

<Example id="multi-selection" />

### Max Selected Dates

Use `maxSelectedDates` with `selectionMode="multiple"` to cap the selection. Here the limit is 3.

<Example id="max-selected-dates" />

### Multiple Months

Set `numOfMonths` to show months side by side. Use `datePicker.getOffset({ months: 1 })` to get the next month's data.

<Example id="multiple-months" />

### Presets

Use `DatePicker.PresetTrigger` for presets like "Last 7 days" or "This month".

<Example id="presets" />

### Min and Max

Use `min` and `max` with `parseDate` to restrict the range. Dates outside it are disabled.

<Example id="min-max" />

### Unavailable

Use `isDateUnavailable` to mark dates as unavailable. This example disables weekends.

<Example id="unavailable" />

### Locale

Set `locale` for language and formatting. Set `startOfWeek` for the first day of the week (0 = Sunday, 1 = Monday).

<Example id="locale" />

### Month Picker

Set `defaultView="month"` and `minView="month"`. Custom `format` and `parse` functions handle the month/year input.

<Example id="month-picker" />

### Year Picker

Set `defaultView="year"` and `minView="year"`. Custom `format` and `parse` functions handle the year input.

<Example id="year-picker" />

### Inline

Set `inline` to render the calendar on the page without a popup.

> With `inline`, omit `Portal`, `Positioner`, and `Content`.

<Example id="inline" />

### Custom Parsing

Use `parse` for custom parsing, so users can type formats like "25/12" or "25/12/24".

<Example id="format-parse" />

### Month Picker Range

Combine `selectionMode="range"` with `defaultView="month"` and `minView="month"`, for example for billing periods.

<Example id="month-picker-range" />

### Year Range

Combine `selectionMode="range"` with `defaultView="year"` and `minView="year"` to select multi-year periods.

<Example id="year-picker-range" />

### Select Today

Call `selectToday` from the context to build a "Today" button.

<Example id="select-today" />

### Fixed Weeks

Set `fixedWeeks` to always show 6 weeks, so the layout doesn't shift between months.

<Example id="fixed-weeks" />

### Form

Set `name` to submit the selected date with a native form. This example also disables weekends with `isDateUnavailable`.

<Example id="form" />

### With Time

Use `CalendarDateTime` from `@internationalized/date` to add a time input. It updates the hour and minute of the
selected value.

<Example id="with-time" />
