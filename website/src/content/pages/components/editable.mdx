## Guides

### Auto-resizing

Set `autoResize` to grow the editable with its content.

```tsx
<Editable.Root placeholder="Placeholder" autoResize>
  {/*...*/}
</Editable.Root>
```

### Max Length

Use `maxLength` to cap the number of characters.

```tsx
<Editable.Root placeholder="Placeholder" autoResize maxLength={10}>
  {/*...*/}
</Editable.Root>
```

### Double Click

By default, edit mode starts when the preview is focused (by pointer or keyboard). Set `activationMode="dblclick"` to
start it on double-click instead.

```tsx
<Editable.Root placeholder="Placeholder" activationMode="dblclick">
  {/*...*/}
</Editable.Root>
```
