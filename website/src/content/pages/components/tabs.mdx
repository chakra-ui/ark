### Lazy Mount

Set `lazyMount` to render a tab's content only when the tab is first activated. This helps when content is large.

Add `unmountOnExit` to unmount the content when the tab is deactivated. It re-renders the next time the tab activates.

<Example id="lazy-mount" />

### Manual Activation

By default, a tab is selected as soon as it receives focus (automatic activation). With manual activation, a tab is
selected only by pressing <kbd>Enter</kbd> or clicking it.

<Example id="manual-activation" />

## Guides

### Router Integration

To sync the active tab with the URL in Next.js, Remix or React Router:

- Set `value` from the current URL path.
- Update the URL path in `onValueChange`.

Here's an example with Remix:

```tsx
import { Tabs } from '@ark-ui/<framework>/tabs'
import { useLocation, useNavigate, Link } from '@remix-run/react'

export default function App() {
  const { pathname } = useLocation()
  const navigate = useNavigate()
  const lastPathFragment = pathname.substring(pathname.lastIndexOf('/') + 1)
  const activeTab = lastPathFragment.length > 0 ? lastPathFragment : 'homepage'

  return (
    <Tabs.Root
      value={activeTab}
      onValueChange={({ value }) => {
        navigate(`/${value === 'home' ? '' : value}`)
      }}
    >
      <Tabs.List>
        <Tabs.Trigger asChild value="home">
          <Link to="">Home</Link>
        </Tabs.Trigger>
        <Tabs.Trigger asChild value="page-1">
          <Link to="page-1">Page 1</Link>
        </Tabs.Trigger>
        <Tabs.Trigger asChild value="page-2">
          <Link to="page-2">Page 2</Link>
        </Tabs.Trigger>
      </Tabs.List>
    </Tabs.Root>
  )
}
```

<FrameworkOnly framework="web">

In `@ark-ui/web`, set the `value` attribute on `ark-tabs` from the current URL. Triggers can wrap an `a` instead of a
`button`:

```html
<ark-tabs value="home">
  <ark-tabs-list>
    <ark-tabs-trigger value="home"><a href="/">Home</a></ark-tabs-trigger>
    <ark-tabs-trigger value="page-1"><a href="/page-1">Page 1</a></ark-tabs-trigger>
  </ark-tabs-list>
</ark-tabs>
```

With a client-side router, update the URL from `valuechange` and set `value` to match:

```ts
const tabs = document.querySelector('ark-tabs')!
tabs.addEventListener('valuechange', (event) => {
  const { value } = event.detail
  router.navigate(value === 'home' ? '/' : `/${value}`)
  tabs.setAttribute('value', value)
})
```
