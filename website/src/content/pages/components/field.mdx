## Examples

`Field` provides `invalid`, `disabled`, `required`, and `readOnly` context to form elements. Most Ark UI components read
it natively, and it also works with standard HTML form elements.

### Input

Use `Field.Input` for a standard input.

<Example id="input" />

### Disabled

Set `disabled` on the root to disable the control and mark every part with `data-disabled`.

<Example id="disabled" />

### Invalid

Set `invalid` to show the error text and mark the control with `aria-invalid`. The error text stays mounted and hidden
while the field is valid.

<Example id="invalid" />

### Indicator

`Field.Indicator` is shown only when its `type` matches the field state: `required`, `invalid`, `valid` or `validating`.
Use it inside the label to show a required marker.

<Example id="indicator" />

### Validation

The field validates the control natively, using attributes like `required` and `type="email"`. Set `validationMode` to
choose when results show (`onSubmit`, `onBlur` or `onChange`). Pass `match` to `Field.ErrorText` to show it only for one
native failure, such as `valueMissing` or `typeMismatch`.

<Example id="validation" />

### Custom Validation

Pass `validate` to run your own rules. Return an error message, a list of messages, or nothing when the value is valid.
It can also return a promise. The messages are available as `errors` on the field context.

<Example id="custom-validation" />

### Server Errors

Pass `errors` to show errors from outside the field, such as a server response. The field is invalid while `errors` is
not empty.

<Example id="server-errors" />

### Textarea

Use `Field.Textarea` for a textarea.

<Example id="textarea" />

### Textarea Autoresize

Set `autoresize` on `Field.Textarea` to grow it as the user types.

<Example id="textarea-autoresize" />

### Select

Use `Field.Select` for a native select.

<Example id="select" />

### Checkbox

<Example component="checkbox" id="with-field" />

Use `RootProvider` with the `useField` hook to access the state and methods from outside the component.

Use `Field.Context` or the `useFieldContext` hook to read the field state and wire up a custom control.
