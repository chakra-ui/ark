## Anatomy

<Anatomy id="popover" />

```tsx
<Popover.Root>
  <Popover.Trigger />
  <Popover.Anchor />
  <Popover.Positioner>
    <Popover.Arrow>
      <Popover.ArrowTip />
    </Popover.Arrow>
    <Popover.Content>
      <Popover.Title />
      <Popover.Description />
      <Popover.CloseTrigger />
    </Popover.Content>
  </Popover.Positioner>
</Popover.Root>
```

### Controlled

Use `open` and `onOpenChange` to control the open state.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `usePopover` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Arrow

Use `Popover.Arrow` and `Popover.ArrowTip` to render an arrow pointing to the trigger.

<Example id="arrow" />

### Placement

Set `positioning` to change the placement.

By default it flips to the opposite side only when there isn't room. Pass a list of placements to `positioning.flip` to
choose other fallbacks, such as above or below.

<Example id="positioning" />

### Close Behavior

The popover closes on blur and on <kbd>esc</kbd>.

- Set `closeOnInteractOutside={false}` to keep it open when clicking or focusing outside.
- Set `closeOnEsc={false}` to keep it open on <kbd>esc</kbd>.

<Example id="close-behavior" />

### Modality

Set `modal` to `true` to make the popover:

- trap focus within its content
- block body scrolling
- disable pointer interactions outside
- hide content behind it from screen readers

`modal={true}` also sets `portalled` to `true`.

<Example id="modal" />

### Anchor

Use `Popover.Anchor` to position the popover relative to a different element than the trigger.

<Example id="anchor" />

### Text Selection

Use `positioning.getAnchorElement` to anchor the popover to the current text selection.

<Example id="text-selection" />

### Same Width

Use `positioning.sameWidth` to match the trigger's width.

<Example id="same-width" />

### Dialog Integration

Inside a dialog, you have two layering options:

1. **Keep the Portal with `lazyMount` and `unmountOnExit`**: the popover unmounts when the dialog closes, so no stale
   DOM nodes remain.

2. **Remove the Portal**: render the popover inline in the dialog content. Watch for z-index issues.

<Example id="with-dialog" />

### Nested

Each nested popover keeps its own open state and positioning.

<Example id="nested" />

### Multiple Triggers

Pass a `value` to each `Popover.Trigger` to share one popover. It repositions to the active trigger without closing.

<Example id="multiple-triggers" />

## Guides

### Available Size

`Popover.Positioner` exposes these CSS variables for styling `Popover.Content`:

```css
/* width of the popover trigger */
--reference-width: <pixel-value>;
/* width of the available viewport */
--available-width: <pixel-value>;
/* height of the available viewport */
--available-height: <pixel-value>;
```

For example, to keep the content within the available height:

```css
[data-popover-content] {
  max-height: calc(var(--available-height) - 100px);
}
```
