<Splitter.Root>

## Examples

<Example id="basic" />

### Context

Use `Splitter.Context` or the `useSplitterContext` hook to resize panels programmatically.

<Example id="context" />

### Vertical

Set `orientation="vertical"` for a vertical splitter.

<Example id="vertical" />

### Collapsible Panels

Set `collapsible` on a panel to let it collapse. `collapsedSize` sets its collapsed size. This suits sidebar layouts.

<Example id="collapsible" />

### Multiple Panels

<Example id="multiple-panels" />

### Root Provider

Use `RootProvider` with the `useSplitter` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Resize Indicator

`Splitter.ResizeTriggerIndicator` shows an indicator on the resize handle.

<Example id="resize-indicator" />

### Dynamic Collapsible

Call `collapsePanel()` and `expandPanel()` based on viewport size, for example to collapse a sidebar on small screens.

<Example id="dynamic-collapsible" />

### Nested

Nest splitters for grid-like layouts. Share a registry from `Splitter.createRegistry()` between them to drag both at
points where horizontal and vertical splitters meet.

<Example id="nested" />
