## Anatomy

<Anatomy id="floating-panel" />

```tsx
<FloatingPanel.Root>
  <FloatingPanel.Trigger />
  <FloatingPanel.Positioner>
    <FloatingPanel.Content>
      <FloatingPanel.DragTrigger>
        <FloatingPanel.Header>
          <FloatingPanel.Title />
          <FloatingPanel.Control>
            <FloatingPanel.StageTrigger />
            <FloatingPanel.CloseTrigger />
          </FloatingPanel.Control>
        </FloatingPanel.Header>
      </FloatingPanel.DragTrigger>
      <FloatingPanel.Body />
      <FloatingPanel.ResizeTrigger />
    </FloatingPanel.Content>
  </FloatingPanel.Positioner>
</FloatingPanel.Root>
```

## Examples

<Example id="basic" />

### Controlled size

Use `size` and `onSizeChange` to control the size.

<Example id="controlled-size" />

### Controlled position

Use `position` and `onPositionChange` to control the position.

<Example id="controlled-position" />

### Anchor Position

Use `getAnchorPosition` to compute the initial position. It runs on open and receives `triggerRect` and `boundaryRect`.

<Example id="anchor-position" />

### Open State

Use `open` and `onOpenChange` to control the open state.

<Example id="controlled-open" />

### Lazy Mount

Set `lazyMount` to render the panel only when first opened.

<Example id="lazy-mount" />

### Context

Use `FloatingPanel.Context` or the `useFloatingPanelContext` hook to access the panel's state.

<Example id="context" />
