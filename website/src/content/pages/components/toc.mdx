## Anatomy

<Anatomy id="toc" />

```tsx
<Toc.Root items={items} scrollEl={() => scrollContainer}>
  <Toc.Content />
  <Toc.Nav>
    <Toc.Title />
    <Toc.List>
      <Toc.Indicator />
      <Toc.Item item={item}>
        <Toc.Link />
      </Toc.Item>
    </Toc.List>
  </Toc.Nav>
</Toc.Root>
```

## Examples

### Basic

Display a table of contents alongside scrollable content. Use the `items` prop to define the list of headings and
`scrollEl` to point to the scrollable container so the TOC can track which section is in view.

<Example id="basic" />

### Nested Headings

Use the `depth` property on each item to represent heading levels (`h2`, `h3`, etc). Apply different styles based on
`depth` to create visual indentation for sub-headings.

<Example id="nested" />

### Root Provider

Use the `useToc` hook with `Toc.RootProvider` to access the TOC state — such as `activeIds` — from outside the
component tree. This is useful when you need to sync the navigation state with other parts of your UI.

<Example id="root-provider" />

### With Collapsible

Wrap `Toc.Nav` in a `Collapsible` to let users show or hide the navigation. Use `Toc.Context` to read `activeItems`
and drive a progress ring that reflects how far through the page the user has scrolled.

<Example id="with-collapsible" />

### With Hover

Use `onMouseEnter` and `onMouseLeave` on `Toc.Nav` to expand the navigation when hovered. Combine with a pinned state
and a toggle button so users can keep it open while reading.

> **Note:** Hover-based interactions are not available on touch screens. Pair this pattern with a pin button or a
> fallback disclosure control to ensure the navigation remains accessible on mobile devices.

<Example id="with-hover" />

### With Indicator

Add `Toc.Indicator` inside `Toc.List` to render a sliding element that animates to track the currently active item.

<Example id="with-indicator" />

### With Tree View

Combine `Toc.Root` with the `TreeView` component for hierarchical section navigation. Use `onActiveChange` to
automatically expand the branch containing the active heading, keeping the tree in sync with the reading position.

<Example id="with-tree-view" />

## Showcase Patterns

The following React examples explore complete product patterns built on top of the table of contents state. They combine
active-section tracking with search, responsive navigation, reading progress, and alternate navigation surfaces.

> **Framework availability:** These showcase patterns are currently available in React. The core examples above remain
> available in React, Solid, Vue, and Svelte.

### Searchable Table of Contents

Filter a long document outline while keeping active-section tracking connected to the complete set of headings. This
pattern is useful for API references, knowledge bases, and other information-dense pages.

<Example id="searchable" framework="react" />

### Reading Timeline

Present document navigation as a reading timeline with completed sections, estimated reading time, and overall progress.
The active item and progress indicator update as the article scrolls.

<Example id="reading-timeline" framework="react" />

### Documentation Sidebar

Build a documentation-style sidebar with breadcrumbs, nested section indentation, active-state highlighting, and a
secondary help action.

<Example id="documentation-sidebar" framework="react" />

### Mobile Drawer

Move the table of contents into a bottom drawer for compact screens. The trigger displays the current section and the
drawer closes automatically after a destination is selected.

<Example id="mobile-drawer" framework="react" />

### Command Menu

Use the same document outline as a keyboard-first command menu. Press <kbd>⌘ K</kbd> or <kbd>Ctrl K</kbd>, filter the
headings, navigate with the arrow keys, and press Enter to jump to a section.

<Example id="command-menu" framework="react" />
