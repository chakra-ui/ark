### Context Menu

Use `Menu.ContextTrigger` to open the menu on right-click. With pen or touch, a long-press of about `700ms` also opens
it.

Pass a `value` to each `Menu.ContextTrigger` to share one menu across targets. Right-clicking another trigger while open
moves the menu there. `onTriggerValueChange` reports the active trigger.

## Guides

### Custom IDs

Ark UI generates menu item ids. A custom `id` breaks the component's internal `getElementById` lookups.

```tsx
// ❌ Don't do this
<Menu.Item id="custom-id" value="custom-value">
  Custom Item
</Menu.Item>

// ✅ Do this
<Menu.Item value="custom-value">
  Custom Item
</Menu.Item>
```

### Links

Render the link as the menu item itself with `asChild`, not as its child.

> This gives the link the menu item's ARIA attributes and keyboard interactions.

A reusable `MenuItemLink`:

```tsx
interface MenuItemLinkProps extends Menu.ItemProps {
  href?: string
  target?: string
}

export const MenuItemLink = (props: MenuItemLinkProps) => {
  const { href, target, children, ...rest } = props
  return (
    <Menu.Item {...rest} asChild>
      <a href={href} target={target}>
        {children}
      </a>
    </Menu.Item>
  )
}
```
