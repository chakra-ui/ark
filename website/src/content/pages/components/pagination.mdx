```tsx
<Pagination.Root>
  <Pagination.PrevTrigger />

  <Pagination.NextTrigger />
</Pagination.Root>
```

## Examples

<Example id="basic" />

### Controlled

Use `page` and `onPageChange` to control the current page.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `usePagination` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Customization

Customize with props like `dir`, `pageSize`, `siblingCount` and `translations`.

<Example id="customized" />

### Context

`Pagination.Context` and the `usePaginationContext` hook expose methods like `setPage`, `setPageSize`, `goToNextPage`,
`goToPreviousPage`, `goToFirstPage` and `goToLastPage`, and properties like `totalPages` and `pageRange`.

<Example id="context" />

### Data Slicing

`slice()` returns the items of a data array for the current page and page size.

<Example id="data-slicing" />

### Page Range

Use `pageRange` to show which items are visible (e.g., "Showing 1-10 of 100 results").

<Example id="page-range" />

### Page Size

Call `setPageSize()` to change items per page, here from a native select.

> **Note:** Use `defaultPageSize` for the initial value when uncontrolled. Use `pageSize` and `onPageSizeChange` to
> control it.

<Example id="page-size-control" />

### Links

Set `type="link"` and pass `getPageUrl` for real navigation that crawlers can follow and users can open in a new tab.
Items and triggers render as anchors with the generated `href`:

<Example id="link" />

To use a router's link component, pass it through `asChild` on the items and triggers. See the
[Composition guide](/docs/guides/composition).
