## Anatomy

<Anatomy id="slider" />

```tsx
<Slider.Root>
  <Slider.Label />
  <Slider.ValueText />
  <Slider.Control>
    <Slider.Track>
      <Slider.Range />
    </Slider.Track>
    <Slider.Thumb>
      <Slider.HiddenInput />
    </Slider.Thumb>
  </Slider.Control>
  <Slider.MarkerGroup>
    <Slider.Marker />
  </Slider.MarkerGroup>
</Slider.Root>
```

## Examples

<Example id="basic" />

### Range

Render multiple `Slider.Thumb` parts for a range slider.

<Example id="range" />

### Marks

Add marks with `Slider.MarkerGroup` and `Slider.Marker`. Each marker's `value` sets its position on the track.

<Example id="with-marks" />

### Min and Max

Set `min` and `max` to change the bounds. They default to `0` and `100`. This example accepts `-10` to `10`.

<Example id="min-max" />

### Granularity

`step` sets the granularity. It defaults to `1`, so values are integers. This example sets `step` to `0.01` for a value
between `5` and `10` with two decimal places.

<Example id="step" />

### Change Events

`onValueChange` fires as the value changes. `onValueChangeEnd` fires when the interaction ends.

<Example id="on-event" />

### Orientation

Set `orientation="vertical"` for a vertical slider. The up and down arrow keys then change the value.

> Give the vertical slider a height in your styles.

<Example id="vertical" />

### Origin

The origin defaults to the start of the track. Set `origin` to `center` to start from the middle.

<Example id="center-origin" />

### Root Provider

Use `RootProvider` with the `useSlider` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Dragging Indicator

Place `Slider.DraggingIndicator` inside `Slider.Thumb` to show an indicator while dragging.

<Example id="dragging-indicator" />

### With Tooltip

Render the thumb as a tooltip trigger to show the current value on hover, focus and drag.

<Example id="with-tooltip" />

### With Number Input

Sync a range slider with number inputs so either one can set the value.

<Example id="with-number-input" />

### Thumb Overlap

Set `minStepsBetweenThumbs` to keep a minimum gap between range thumbs, as in a price filter.

<Example id="thumb-overlap" />

### Thumb Collision

`thumbCollisionBehavior` sets what happens when thumbs collide while dragging: `push` (default), `swap` or `none`.

<Example id="thumb-collision" />
