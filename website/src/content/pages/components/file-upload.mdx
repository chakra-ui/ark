## Guides

### File Previews

Set `type` on `ItemPreview` to render a preview per file format.

- `type="image/*"`: image thumbnails via `ItemPreviewImage`
- `type="video/*"`: video files
- `type="application/pdf"`: PDF files
- `type=".*"`: fallback for any file

```tsx
<FileUpload.ItemPreview type="image/*">
  <FileUpload.ItemPreviewImage />
</FileUpload.ItemPreview>

<FileUpload.ItemPreview type="video/*">
  <VideoIcon />
</FileUpload.ItemPreview>

<FileUpload.ItemPreview type="application/pdf">
  <PdfIcon />
</FileUpload.ItemPreview>

<FileUpload.ItemPreview type=".*">
  <FileIcon />
</FileUpload.ItemPreview>
```

### Disable Dropzone

Set `allowDrop={false}` to disable drag-and-drop.

```tsx
<FileUpload.Root allowDrop={false}>{/* ... */}</FileUpload.Root>
```

### Prevent Document Drop

Dropping files outside the dropzone doesn't navigate away by default. Set `preventDocumentDrop={false}` to turn this
off.

```tsx
<FileUpload.Root preventDocumentDrop={false}>{/* ... */}</FileUpload.Root>
```

### Prevent Double Open

Set `disableClick` on `Dropzone` when it contains a `Trigger`, so the file picker doesn't open twice.

```tsx
<FileUpload.Dropzone disableClick>
  <FileUpload.Trigger>Choose Files</FileUpload.Trigger>
  Drag files here
</FileUpload.Dropzone>
```
