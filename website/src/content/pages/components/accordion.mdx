## Guides

### Content Animation

Animate the content size with the `--height` and `--width` CSS variables:

```css
@keyframes slideDown {
  from {
    opacity: 0.01;
    height: 0;
  }
  to {
    opacity: 1;
    height: var(--height);
  }
}

@keyframes slideUp {
  from {
    opacity: 1;
    height: var(--height);
  }
  to {
    opacity: 0.01;
    height: 0;
  }
}

[data-accordion-item-content][data-state='open'] {
  animation: slideDown 250ms ease-in-out;
}

[data-accordion-item-content][data-state='closed'] {
  animation: slideUp 200ms ease-in-out;
}
```
