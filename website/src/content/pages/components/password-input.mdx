## Examples

<Example id="basic" />

### Autocomplete

Set `autoComplete` to control autocompletion:

- `new-password`: the user is creating a new password.
- `current-password`: the user is entering an existing password.

<Example id="autocomplete" />

### Controlled Visibility

Use `visible` and `onVisibilityChange` to control visibility.

<Example id="controlled-visibility" />

### Root Provider

Use `RootProvider` with the `usePasswordInput` hook to access the state and methods from outside the component.

<Example id="root-provider" />

<Example id="with-field" />

### Password Managers

Set `ignorePasswordManager` for non-login fields like API keys, secure notes or temporary passwords.

> **Only works for 1Password, LastPass, Bitwarden, Dashlane and Proton Pass.**

<Example id="ignore-password-manager" />

### Strength Meter

Pair with a strength library to show live feedback. This example uses
[`check-password-strength`](https://www.npmjs.com/package/check-password-strength).

<Example id="strength-meter" />
