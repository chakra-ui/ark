## Anatomy

```tsx
<NumberFlow.Root>
  <NumberFlow.Segments />
  <NumberFlow.HiddenValueText />
</NumberFlow.Root>
```

`Segments` renders a `Digit` per rolling digit and a `Symbol` per separator, currency sign or literal. Each `Digit`
renders a `DigitTrack`, a strip of `DigitCell`s translated to show the right cell. Pass a render function to `Segments`
to compose the parts yourself:

```tsx
<NumberFlow.Root>
  <NumberFlow.Segments>
    {(segment) =>
      segment.kind === 'digit' ? (
        <NumberFlow.Digit segment={segment}>
          <NumberFlow.DigitTrack segment={segment} />
        </NumberFlow.Digit>
      ) : (
        <NumberFlow.Symbol segment={segment} />
      )
    }
  </NumberFlow.Segments>
  <NumberFlow.HiddenValueText />
</NumberFlow.Root>
```

## Examples

### Basic

The number rolls to `value` whenever it changes. Use `defaultValue` to let the component own the value.

### Formatting

`formatOptions` is passed to `Intl.NumberFormat`, so currency, percent, compact notation and precision all work. Only
digits roll. Signs, separators and currency symbols swap in place.

<Example id="formatting" />

### Pricing

Set `trend` so every digit rolls in the direction the price moved.

<Example id="pricing" />

### Trend

The root carries `data-trend` (`up`, `down` or `none`) during the roll. Use it to color by direction.

<Example id="trend" />

### Continuous

Each digit takes its shortest path by default, so `9` to `0` rolls forward one step. Set `continuous` to spin through
every value in between, so `120` to `245` reads as counting rather than a cut.

<Example id="continuous" />

### Timing

`spinTiming` controls the roll and `transformTiming` controls digits entering and leaving. Both take CSS `duration` and
`easing`. `stagger` delays each digit behind the previous one.

<Example id="timing" />

### Locale

The number uses the locale from `LocaleProvider` or the `locale` prop. Non-Latin numerals roll through their own glyphs,
so `ar-EG` rolls through `٠` to `٩`.

<Example id="locale" />

### Prefix and Suffix

`prefix` and `suffix` add static text around the number. They never roll and are part of the accessible label.

<Example id="prefix-suffix" />

### Composition

Pass a function as the child of `Segments` to render each segment. Digit segments carry their decimal `place` (`0` is
the ones column, negatives are fraction digits). Symbols carry their `Intl` `type`. Use these to style the cents or
currency sign separately. `Segments` keys every segment, so digits keep rolling when the number gains or loses a digit.

<Example id="composition" />

### With Timer

Pair `NumberFlow` with the [Timer](/docs/components/timer) for a rolling countdown. Read the time from `useTimer`.
Render one `NumberFlow.Root` per unit with `minimumIntegerDigits: 2`, and set `trend={-1}` so digits roll down.

<Example id="with-timer" />

### Live Announcements

Set `live` to announce changes to screen readers. `HiddenValueText` announces the value once the roll settles, so a fast
counter is read once, not per step.

<Example id="live" />

### Root Provider

Use the `useNumberFlow` hook with `RootProvider` to read the value and call `setValue` from outside.

## Guides

### Styling

Structural styles are inline: each digit is clipped to one line and the track is a vertical strip of `1lh` cells. You
handle typography and color.

```css
[data-number-flow-root] {
  font-variant-numeric: tabular-nums;
}

[data-number-flow-symbol] {
  white-space: pre;
}

[data-number-flow-digit] {
  vertical-align: top;
}
```

Use a font with tabular figures. Proportional digits change width as they roll and make the number jitter.

The root exposes `data-state` (`idle` or `rolling`), `data-trend` and `data-reduced-motion`. Digits carry `data-place`.
Symbols carry `data-type` with their `Intl.NumberFormat` part type, such as `currency` or `group`.

<FrameworkOnly framework="web">

### Web Components

In `@ark-ui/web`, `<ark-number-flow-segments>` renders digits and symbols itself, with no render function. Style them
with the data attributes above. `formatOptions` is a property. Writing the `value` property rolls the number.

```html
<ark-number-flow default-value="1248" trend="-1">
  <ark-number-flow-segments></ark-number-flow-segments>
  <ark-number-flow-value-text></ark-number-flow-value-text>
</ark-number-flow>
```

```ts
const flow = document.querySelector('ark-number-flow')!
flow.formatOptions = { style: 'currency', currency: 'USD' }
flow.value = 1299
```

`<ark-number-flow-value-text>` plays the role of `HiddenValueText`.

</FrameworkOnly>

### Accessibility

By default the root has `role="img"` and an `aria-label` with the formatted value, so assistive technology reads the
number, not the cells. `HiddenValueText` is visually hidden and silent.

With `live`, the root drops its role and `HiddenValueText` becomes a polite status region with the settled value. Always
render `HiddenValueText` with `live`. Without it, nothing is announced.

With reduced motion preferred, the number snaps to its new value. Set `respectMotionPreference` to `false` to roll
anyway.
