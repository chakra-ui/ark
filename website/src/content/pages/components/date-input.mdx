id: date-input
title: Date Input
description: A segment-based date input that allows users to enter dates by navigating individual date parts.
---

<ComponentPreview id="DateInput" />

## Anatomy

<Anatomy id="date-input" />

```tsx
<DateInput.Root>
  <DateInput.Label />
  <DateInput.Control>
    <DateInput.SegmentGroup>
      <DateInput.Segment />
    </DateInput.SegmentGroup>
  </DateInput.Control>
  <DateInput.HiddenInput />
</DateInput.Root>
```

## Examples

<Example id="basic" />

### Default Value

Set `defaultValue` with `parseDate` for the initial date.

<Example id="default-value" />

### Controlled

Use `value` and `onValueChange` to control the value.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useDateInput` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Granularity

Set `granularity` to choose which fields show: `day`, `hour`, `minute` or `second`.

<Example id="granularity" />

### Time Only

Set `granularity` to `minute` or `second` and pass a `formatter` with only time fields. Set `hourCycle` to switch
between 12 and 24 hour formats.

<Example id="time-only" />

### Range

Set `selectionMode="range"` and render two `SegmentGroup` components with `index` set to `0` and `1`.

<Example id="range" />

### Min and Max

Set `min` and `max` with `parseDate` to restrict the range. Dates outside it are marked invalid.

<Example id="min-max" />

### Disabled

Set `disabled` to block interaction.

<Example id="disabled" />

### Read Only

Set `readOnly` to prevent edits while keeping the input focusable.

<Example id="read-only" />

### Invalid

Set `invalid` to show an error state.

<Example id="invalid" />

### Leading Zeros

Set `shouldForceLeadingZeros` to pad numeric segments with a leading zero.

<Example id="leading-zeros" />

### Localized

Set `locale` for the language and regional format of the segments.

<Example id="localized" />

### RTL

Set `dir="rtl"` for right-to-left languages.

<Example id="rtl" />

### With Clear Button

Call `clearValue` from `useDateInput` (via `RootProvider`) to build a clear button.

<Example id="with-clear-button" />

### With Date Picker

Sync `DateInput` and `DatePicker` through `onValueChange` so users can type a date or pick one from a calendar.

<Example id="with-date-picker" />
