## Anatomy

<Anatomy id="tooltip" />

```tsx
<Tooltip.Root>
  <Tooltip.Trigger />
  <Tooltip.Positioner>
    <Tooltip.Arrow>
      <Tooltip.ArrowTip />
    </Tooltip.Arrow>
    <Tooltip.Content />
  </Tooltip.Positioner>
</Tooltip.Root>
```

## Examples

<Example id="basic" />

### Controlled

Pass `open` to control the tooltip.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useTooltip` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Arrow

Add `Tooltip.Arrow` and `Tooltip.ArrowTip` to point at the trigger.

<Example id="arrow" />

### Delay

Set `openDelay` and `closeDelay`.

<Example id="delay" />

### Positioning

Use `positioning` to place the tooltip relative to the trigger.

<Example id="positioning" />

### Follow Cursor

Use `positioning.getAnchorElement` with the pointer position to make the tooltip follow the cursor.

<Example id="follow-cursor" />

### Context

Read the state and methods with `Tooltip.Context` or the `useTooltipContext` hook.

<Example id="context" />

### Within Fixed Containers

Inside a fixed-position container, set `positioning.strategy` to `"fixed"`.

<Example id="within-fixed" />

### Multiple Triggers

Pass a `value` to each `Tooltip.Trigger` to share one tooltip. It moves to the hovered trigger without closing.

<Example id="multiple-triggers" />

### With Checkbox

Merge `Tooltip.Trigger` onto `Checkbox.Root` with the render API.

<Example id="with-checkbox" />

### With Menu Trigger

Merge `Tooltip.Trigger` onto `Menu.Trigger`.

<Example id="with-menu-trigger" />

### With Menu Item

Put a tooltip on a disabled `Menu.Item`. Portal it so the menu does not clip it.

<Example id="with-menu-item" />

### With Dialog

Merge `Tooltip.Trigger` onto `Dialog.Trigger`.

<Example id="with-dialog" />

### With Popover
