```tsx
<RatingGroup.Root>
  <RatingGroup.Label />
  <RatingGroup.Control>
    <RatingGroup.Item>

    <RatingGroup.HiddenInput />
  </RatingGroup.Control>

```

## Examples

<Example id="basic" />

### Controlled

Use `value` and `onValueChange` to control the value.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useRatingGroup` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Field

`Field` wires up the label, helper text, error text and ARIA attributes.

<Example id="with-field" />

### Half Rating

Set `allowHalf` to `true` to allow `0.5` steps. Render a half icon when `half` is set in the item's render callback.

<Example id="half-star" />

### Forms

Pass `name` to render a hidden input that submits the value with the form.

<Example id="form-usage" />

### Disabled

Set `disabled` to `true` to disable the rating group.

<Example id="disabled" />
