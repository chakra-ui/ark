## Examples

### Basic

Drag the handles to resize the selection. Drag inside it to pan the image.

<Example id="basic" />

### Aspect Ratio

Use `aspectRatio` to lock the crop area, such as `16/9` for widescreen or `1` for square.

<Example id="aspect-ratio" />

### Circle Crop

Set `cropShape="circle"` for a circular selection, as used for avatars.

<Example id="circle" />

### Initial Crop

Use `initialCrop` to set the starting crop area as `x`, `y`, `width`, and `height` in pixels.

<Example id="initial-crop" />

### Controlled Zoom

Use `zoom` and `onZoomChange` to control zoom, for example from external buttons.

<Example id="controlled-zoom" />

### Zoom Limits

Set `minZoom` and `maxZoom` to limit how far users can zoom in or out.

<Example id="zoom-limits" />

### Rotation

Use `rotation` and `onRotationChange` to rotate the image. Values are in degrees.

<Example id="rotation" />

### Flip

Use `flip` with `horizontal` and `vertical` booleans to flip the image.

<Example id="flip" />

### Min and Max Size

Use `minWidth`, `minHeight`, `maxWidth`, and `maxHeight` to bound the crop area size.

<Example id="min-max-size" />

### Fixed Crop Area

Set `fixedCropArea` to keep the crop area still while the image moves underneath.

<Example id="fixed" />

### Crop Preview

Call `getCroppedImage()` from the context to get the result. Pass `{ output: 'dataUrl' }` for a base64 string to use as
an `img` src.

<Example id="crop-preview" />

### Reset

Call `reset()` from the context to restore the initial state, for example from a "start over" button.

<Example id="reset" />

### Events

Use `onCropChange` and `onZoomChange` to track the crop and zoom, for example to sync external state or show a live
preview.

<Example id="events" />

### Context

Use `ImageCropper.Context` to reach the API anywhere inside the root, including `zoomBy`, `rotateBy`, and `setZoom`.

<Example id="context" />

### Root Provider

Use `RootProvider` with `useImageCropper` to control the cropper from outside the component tree, such as from a custom
toolbar.

<Example id="root-provider" />

## Guides

### Web Components

In `@ark-ui/web`, these actions are methods on `ark-image-cropper`: `zoomBy`, `rotateBy`, `flipHorizontally`,
`flipVertically`, `resize`, `setCrop`, and `reset`. Changes dispatch `cropchange`, `zoomchange`, `rotationchange`, and
`flipchange`. To get the cropped image, await `ready` and call `getCroppedImage` on the element's `api`:

```ts
const cropper = document.querySelector('ark-image-cropper')!
await cropper.ready
const dataUrl = await cropper.api!.getCroppedImage({ output: 'dataUrl' })
```
