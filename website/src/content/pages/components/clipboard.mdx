## Examples

<Example id="basic" />

### Controlled

Use `value` and `onValueChange` to control the clipboard value.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useClipboard` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Context

Use `Clipboard.Context` or the `useClipboardContext` hook to read `copied`, `value` and `setValue`.

<Example id="context" />

### Copy Status

`onStatusChange` fires on each copy. Use its `copied` property to show a success message.

<Example id="copy-status" />

### Timeout

Set `timeout` to change how long the copied status lasts. The default is 3000ms.

<Example id="timeout" />

### Value Text

Use `Clipboard.ValueText` to display the current clipboard value.

<Example id="value-text" />
