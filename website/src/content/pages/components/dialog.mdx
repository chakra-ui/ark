### Alert Dialog

Use `role="alertdialog"` for critical confirmations or destructive actions. Unlike a regular dialog:

- **Automatic focus**: the close/cancel button gets focus on open, so the safest action comes first
- **Explicit dismissal**: an outside click doesn't close it; only a button or <kbd>Escape</kbd> does

## Guides

### Close Behavior

- `closeOnEscape={false}` - Prevent closing on <kbd>Escape</kbd>
- `closeOnInteractOutside={false}` - Prevent closing on outside click

For conditional control, use `onEscapeKeyDown` or `onInteractOutside` with `e.preventDefault()`.

### Conditional Rendering

Unmounting `Dialog.Root` on toggle can break focus, scroll lock, and cleanup. Keep the root mounted and control it with
`open` / `onOpenChange`.

To remove portal content from the DOM while closed, add `lazyMount` and `unmountOnExit` to the root.

```tsx
import { Dialog } from '@ark-ui/react/dialog'
import { Portal } from '@ark-ui/react/portal'

// ❌ Avoid
const Dont = () => {
  if (isOpen) {
    return (
      <Dialog.Root open={isOpen} onOpenChange={(e) => setOpen(e.open)}>
        <Portal>...</Portal>
      </Dialog.Root>
    )
  }
  return null
}

// ✅ Prefer
const Do = () => {
  return (
    <Dialog.Root open={isOpen} onOpenChange={(e) => setOpen(e.open)} lazyMount unmountOnExit>
      <Portal>...</Portal>
    </Dialog.Root>
  )
}
```

### Z-Index Stacking

Use a shared overlay z-index with `--layer-index` to keep stacked overlays in order:

```css
[data-dialog-content] {
  z-index: calc(var(--z-index-overlay) + var(--layer-index, 0));
}

[data-dialog-positioner] {
  z-index: var(--z-index, var(--z-index-overlay));
}

[data-dialog-backdrop] {
  z-index: calc(var(--z-index, var(--z-index-overlay)) - 1);
}
```

See the [Styling guide](/docs/guides/styling#z-index).

### Dynamic Imports

With `lazyMount` and `React.lazy` or Next.js `dynamic`, wrap the imported component in `Suspense`:

```tsx
import { Dialog } from '@ark-ui/react/dialog'
import { Suspense } from 'react'
import dynamic from 'next/dynamic'

const HeavyComponent = dynamic(() => import('./HeavyComponent'))

export const Demo = () => (
  <Dialog.Root lazyMount>
    <Dialog.Trigger>Open</Dialog.Trigger>
    <Dialog.Content>
      <Suspense fallback={<div>Loading...</div>}>
        <HeavyComponent />
      </Suspense>
    </Dialog.Content>
  </Dialog.Root>
)
```
