## Meter or Progress?

A meter shows a reading within a range, like storage used or battery left. A progress bar tracks a task and finishes
with it. Use `Progress` for loading and uploads, and `Meter` for readings.

## Examples

### Basic

Pass a `defaultValue` between `min` and `max` (`0` and `100` by default). It is formatted as a percentage.

<Example id="basic" />

### Value State

`low`, `high` and `optimum` split the range into regions, like the HTML `<meter>` element. The root, track and indicator
expose the result as `data-state`: `optimal`, `suboptimal` or `least-optimal`.

Put `optimum` below `low` when lower is better (server load) and above `high` when higher is better (battery). Regions
are exclusive at the optimal end, so with `high={80}` a value of `80` is still `suboptimal`.

<Example id="value-state" />

### Format Options

`formatOptions` is passed to `Intl.NumberFormat`. Any style other than `percent` formats the raw value, which suits
currency and units.

### Value Text

The `value` translation describes the value in words. It sets both `ValueText` and the announced `aria-valuetext`.

Set `min` and `max` for ranges that don't start at zero.

## Guides

### Styling

The indicator's `width` (or `height` when vertical) is set inline, so the track only needs a size and
`overflow: hidden`. The root exposes the fill as `--percent`.

```css
[data-meter-indicator][data-state='optimal'] {
  background: green;
}

[data-meter-indicator][data-state='suboptimal'] {
  background: orange;
}

[data-meter-indicator][data-state='least-optimal'] {
  background: red;
}
```

### Accessibility

The root has `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and `aria-valuetext` set from the
formatted value. `Label` names the meter. Without one, pass an `aria-label` to the root. `ValueText` is hidden from
assistive technology because `aria-valuetext` already announces the value.
