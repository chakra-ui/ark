## Meter or Progress?

A meter shows a measurement that stays within a range: storage used, battery remaining, a password's strength. A
progress bar shows how far a task has come and finishes when the task does. Use `Progress` for loading and uploads, and
`Meter` for everything that is a reading rather than a countdown to done.

## Examples

### Basic

Pass a `defaultValue` between `min` and `max` (`0` and `100` by default). The value is formatted as a percentage.

<Example id="basic" />

### Value State

`low`, `high`, and `optimum` split the range into regions, the same way the HTML `<meter>` element does. The root,
track, and indicator expose the result as `data-state`: `optimal`, `suboptimal`, or `least-optimal`.

Put `optimum` below `low` when lower is better, as with server load, and above `high` when higher is better, as with
battery charge. The regions are exclusive at the optimal end, so with `high={80}` a value of exactly `80` is still
`suboptimal`.

### Format Options

`formatOptions` goes to `Intl.NumberFormat`. Any style other than `percent` formats the value itself rather than its
percentage, which suits currency and units.

### Value Text

Use the `value` translation to describe the value in words. It sets both the rendered `ValueText` and the

## Guides

### Styling

The indicator's `width` (or `height` when vertical) is set inline from the value, so the track only needs a size and
`overflow: hidden`. The root also exposes the fill as the `--percent` CSS variable.

```css
[data-meter-indicator][data-state='optimal'] {
  background: green;
}

[data-meter-indicator][data-state='suboptimal'] {
  background: orange;
}

[data-meter-indicator][data-state='least-optimal'] {
  background: red;
}
```

### Accessibility

The root has `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-valuetext` set from the
value and its formatting. `Label` names the meter; without one, pass an `aria-label` to the root. `ValueText` is hidden
from assistive technology, because `aria-valuetext` already announces the value.
