## Examples

### Placeholder

Set `placeholder` to replace the default `○`.

<Example id="custom-placeholder" />

### Blur on Complete

The last input keeps focus when filled. To blur it on completion, blur the focused element in `onValueComplete`.

<Example id="blur-on-complete" />

### OTP Mode

Set `otp` to `true` to add `autocomplete="one-time-code"`, which triggers OTP auto-suggestion on phones.

<Example id="otp-mode" />

### Masking

Set `mask` to `true` to hide sensitive values, like `<input type="password"/>`.

<Example id="mask" />

### Change Events

- `onValueChange`: the value changed.
- `onValueComplete`: all fields are filled, by typing or pasting.
- `onValueInvalid`: the entered value doesn't match the `type`.

### Verify on Complete

Verify the code in `onValueComplete`. If it's wrong, set `invalid` and the control shakes.

<Example id="verify-on-complete" />

### Field

`Field` wires up the label, helper text, error text and ARIA attributes.

<Example id="with-field" />

### Root Provider

Use `RootProvider` with the `usePinInput` hook to access the state and methods from outside the component.

<Example id="root-provider" />
