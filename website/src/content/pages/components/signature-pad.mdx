## Examples

<Example id="basic" />

### Controlled

Control the paths with `paths` and `onDraw` (React/Solid), `v-model:paths` (Vue), `bind:paths` (Svelte), or the `paths`
attribute as JSON with the `draw` event (Web). The example tracks the path count and clears the signature from outside.

<Example id="controlled" />

### Image Preview

Show the drawn signature as an image preview before saving it.

<Example id="image-preview" />

### Field

`Field` wires up the label, helper text, error text and ARIA attributes.

<Example id="with-field" />

### Root Provider

Use `RootProvider` with the `useSignaturePad` hook to access the state and methods from outside the component.

<Example id="root-provider" />
