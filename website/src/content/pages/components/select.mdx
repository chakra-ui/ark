## Guides

### Type Safety

Use the `Select.RootComponent` type to build wrappers that keep collection items typed.

```tsx
const Select: ArkSelect.RootComponent = (props) => {
  return <ArkSelect.Root {...props}>{/* ... */}</ArkSelect.Root>
}
```

`onValueChange` and other callbacks then infer the item type:

```tsx
const App = () => {
  const collection = createListCollection({
    initialItems: [
      { label: 'React', value: 'react' },
      { label: 'Vue', value: 'vue' },
    ],
  })
  return (
    <Select
      collection={collection}
      onValueChange={(e) => {
        // e.items is typed as Array<{ label: string, value: string }>
        console.log(e.items)
      }}
    >
      {/* ... */}
    </Select>
  )
}
```

### Hidden Select

`Select.HiddenSelect` renders a visually hidden native `<select>`. It enables:

- **Form submission**: native submission and serialization work because a real `<select>` exists.
- **Browser auto-fill**: browsers can fill it from previously submitted data.
- **Progressive enhancement**: forms still work if JavaScript fails to load.

```tsx
<Select.Root>
  <Select.HiddenSelect />
  {/* Other Select components */}
</Select.Root>
```

It stays in sync with the select's value.

### Virtualization

Avoid `Select.HiddenSelect` with virtualized collections. It renders an `<option>` for every item. Use
`Select.HiddenInput` instead. It renders one hidden `<input>` per selected value, using the root's `name`, `form` and
`disabled`:

```tsx
<Select.Root collection={collection} name="item">
  {/* Other Select components */}
  <Select.HiddenInput />
</Select.Root>
```

### Empty State

Check the collection size with `useSelectContext` to show an empty state:

```tsx
const SelectEmpty = (props: React.ComponentProps<'div'>) => {
  const select = useSelectContext()
  if (select.collection.size === 0) {
    return <div {...props} role="presentation" />
  }
  return null
}
```

Render it inside the content:

```tsx
<Select.Content>
  <SelectEmpty>No items to display</SelectEmpty>
  {/* Your items */}
</Select.Content>
```

### Available Size

`Select.Positioner` exposes these CSS variables for styling `Select.Content`:

```css
/* width of the select trigger */
--reference-width: <pixel-value>;
/* width of the available viewport */
--available-width: <pixel-value>;
/* height of the available viewport */
--available-height: <pixel-value>;
```

For example, to keep the content within the available height:

```css
[data-select-content] {
  max-height: calc(var(--available-height) - 100px);
}
```
