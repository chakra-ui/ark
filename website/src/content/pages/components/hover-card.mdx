## Anatomy

<Anatomy id="hover-card" />

```tsx
<HoverCard.Root>
  <HoverCard.Trigger />
  <HoverCard.Positioner>
    <HoverCard.Arrow>
      <HoverCard.ArrowTip />
    </HoverCard.Arrow>
    <HoverCard.Content />
  </HoverCard.Positioner>
</HoverCard.Root>
```

## Examples

<Example id="basic" />

### Controlled

Use `open` and `onOpenChange` to control the open state.

<Example id="controlled" />

### Root Provider

Use `RootProvider` with the `useHoverCard` hook to access the state and methods from outside the component.

<Example id="root-provider" />

### Delay

Use `openDelay` and `closeDelay` to set the open and close delays.

<Example id="delay" />

### Positioning

Use `positioning` to set the placement and distance from the trigger.

<Example id="positioning" />

### Context

Read the state with `HoverCard.Context` or the `useHoverCardContext` hook.

<Example id="context" />

### Multiple Triggers

Give each `HoverCard.Trigger` a `value` to share one card across triggers. The card moves to the active trigger without
closing.

<Example id="multiple-triggers" />
