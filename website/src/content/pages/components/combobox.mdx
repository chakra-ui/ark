## Guides

### Router Links

Pass `navigate` to `Combobox.Root` to use your router. With TanStack Router:

```tsx
import { Combobox } from '@ark-ui/<framework>/combobox'
import { useNavigate } from '@tanstack/react-router'

function Demo() {
  const navigate = useNavigate()
  return (
    <Combobox.Root
      navigate={(e) => {
        navigate({ to: e.node.href })
      }}
    >
      {/* ... */}
    </Combobox.Root>
  )
}
```

### Custom Objects

The collection expects objects with `label` and `value` by default. For other shapes, map them with `itemToString` and
`itemToValue`.

```tsx
const items = [
  { country: 'United States', code: 'US', flag: '🇺🇸' },
  { country: 'Canada', code: 'CA', flag: '🇨🇦' },
  { country: 'Australia', code: 'AU', flag: '🇦🇺' },
  // ...
]

const { collection } = useListCollection({
  initialItems: items,
  itemToString: (item) => item.country,
  itemToValue: (item) => item.code,
})
```

### Type Safety

Type a wrapper with `Combobox.RootComponent` to keep collection items typed.

```tsx
const Combobox: ArkCombobox.RootComponent = (props) => {
  return <ArkCombobox.Root {...props}>{/* ... */}</ArkCombobox.Root>
}
```

Callbacks like `onValueChange` then infer the item type:

```tsx
const App = () => {
  const { collection } = useListCollection({
    initialItems: [
      { label: 'React', value: 'react' },
      { label: 'Vue', value: 'vue' },
    ],
  })
  return (
    <Combobox
      collection={collection}
      onValueChange={(e) => {
        // e.items is typed as Array<{ label: string, value: string }>
        console.log(e.items)
      }}
    >
      {/* ... */}
    </Combobox>
  )
}
```

### Large Datasets

For large lists, set `limit` on `useListCollection` to cap how many items render.

```tsx {3}
const { collection } = useListCollection({
  initialItems: items,
  limit: 10,
})
```

### Available Size

`Combobox.Positioner` exposes these CSS variables for styling `Combobox.Content`:

```css
/* width of the combobox control */
--reference-width: <pixel-value>;
/* width of the available viewport */
--available-width: <pixel-value>;
/* height of the available viewport */
--available-height: <pixel-value>;
```

For example, keep the content within the available height:

```css
[data-combobox-content] {
  max-height: calc(var(--available-height) - 100px);
}
```

### Web Components

In `@ark-ui/web`, the guides above map to the `ark-combobox` element:

- Assign items as a collection with `createListCollection`, including `itemToString` and `itemToValue` for custom
  objects. Items can also come from a `<script type="application/json">` child or from `ark-combobox-item` markup.
- Type the element with its item type to type `event.detail.items`: `querySelector<ComboboxElement<Country>>(...)`.
- Use the `filter` attribute (`contains`, `starts-with`, or `none`) and the `limit` attribute instead of
  `useListCollection`.
- Assign `navigate` as a property for router links.

```ts
import { type ComboboxElement, createListCollection } from '@ark-ui/web/combobox'

const combobox = document.querySelector<ComboboxElement<Country>>('ark-combobox')!
combobox.collection = createListCollection({
  items: countries,
  itemToString: (item) => item.country,
  itemToValue: (item) => item.code,
})
combobox.navigate = ({ href }) => router.push(href)
```
