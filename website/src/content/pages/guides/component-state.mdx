Need to access a component's state? You have four options:

| Approach                        | When to use it                                |
| ------------------------------- | --------------------------------------------- |
| The `render` prop               | Read the state of the part you are replacing  |
| `Component.Context`             | Quick inline access via render props          |
| `use*Context` hooks             | Build custom child components that read state |
| `useComponent` + `RootProvider` | Control the component from outside            |

## The render Prop

When you replace a part with your own element, `render` hands you that part's state alongside its props — no context
needed for the thing you are already rendering.

```tsx
<Collapsible.Trigger render={(props, state) => <button {...props}>{state.open ? 'Open' : 'Closed'}</button>} />
```

Each part carries the state its machine exposes, so a trigger knows whether it is open, an item whether it is
highlighted, a swatch whether it is checked. See [Composition](/docs/guides/composition) for the shape `render` takes in
each framework.

> **Solid**: the state arrives as an accessor, and the props as a function to call:
> `render={(props, state) => <button {...props()}>{state().open ? 'Open' : 'Closed'}</button>}`

## Context Hooks

Every component exports a `use*Context` hook (like `useDialogContext` or `useMenuContext`). Call it from any child
component to access state and methods—no render props needed.

```tsx
import { Dialog, useDialogContext } from '@ark-ui/react/dialog'

function CustomCloseButton() {
  const dialog = useDialogContext()
  return <button onClick={() => dialog.setOpen(false)}>Close ({dialog.open ? 'open' : 'closed'})</button>
}

export const Demo = () => (
  <Dialog.Root>
    <Dialog.Trigger>Open</Dialog.Trigger>
    <Dialog.Content>
      <CustomCloseButton />
    </Dialog.Content>
  </Dialog.Root>
)
```

The hook returns the same API as `Component.Context`, just without the nesting.

## Choosing the Right Approach

- **`Component.Context`** — Quick inline access for conditional rendering
- **`use*Context` hooks** — Build reusable child components that need parent state
- **`useComponent` + `RootProvider`** — Trigger actions from outside (like opening a dialog from a menu item)
