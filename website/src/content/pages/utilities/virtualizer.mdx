## Usage

The virtualizer renders only the items in the scroll viewport, plus a few extra for smooth scrolling. There are three
flavors, each a hook plus components:

- `useListVirtualizer` + `ListVirtualizer` for lists that scroll inside their own container.
- `useGridVirtualizer` + `GridVirtualizer` for grids of rows and cells.
- `useWindowVirtualizer` + `WindowVirtualizer` for lists that scroll with the window or nearest scrollable ancestor.

Pass the hook's result to `Root` as `value`, render the spacer with `Content`, and map the virtual items to `Item`.

```tsx
import { ListVirtualizer, useListVirtualizer } from '@ark-ui/react/virtualizer'

const virtualizer = useListVirtualizer({
  count: items.length,
  estimatedSize: () => 48,
})

<ListVirtualizer.Root value={virtualizer}>
  <ListVirtualizer.Content>
    {virtualizer.getVirtualItems().map((item) => (
      <ListVirtualizer.Item key={item.key} item={item}>
        {items[item.index]}
      </ListVirtualizer.Item>
    ))}
  </ListVirtualizer.Content>
</ListVirtualizer.Root>
```

`Root` is the scroll container. Give it a fixed height (or width when horizontal). `Content` is a spacer sized to the
whole list. `Item` is positioned with a `transform`, so give items a height that matches `estimatedSize`, or measure
them as shown below.

The virtualizer re-measures when the container resizes, so it works inside tabs, dialogs and collapsed panels. Set
`observeScrollElementSize: false` to opt out.

### Grid

Map `getVirtualRows()` to `Row` and each row's `columns` to `Cell`. `Cell` reads its row from context, so it only needs
the `column`. Rows accept `measure`.

### Using the Context

`Context` exposes the virtualizer to children, for derived state like the visible range.

```tsx
<ListVirtualizer.Root value={virtualizer}>
  <ListVirtualizer.Context>
    {(virtualizer) => <span>{virtualizer.getVirtualItems().length} items rendered</span>}
  </ListVirtualizer.Context>
</ListVirtualizer.Root>
```

### Composing with other components

Use the `render` prop to render a component's scroll container as `ListVirtualizer.Root` and its items as
`ListVirtualizer.Item`. The component keeps its roles, ids and handlers; the virtualizer adds positioning and
`aria-posinset` / `aria-setsize`.

```tsx
<Combobox.List render={<ListVirtualizer.Root value={virtualizer} />}>
  <ListVirtualizer.Content>
    {virtualizer.getVirtualItems().map((virtualItem) => {
      const item = collection.items[virtualItem.index]
      return (
        <Combobox.Item key={item.value} item={item} render={<ListVirtualizer.Item item={virtualItem} />}>
          <Combobox.ItemText>{item.label}</Combobox.ItemText>
        </Combobox.Item>
      )
    })}
  </ListVirtualizer.Content>
</Combobox.List>
```

Forward the component's `scrollToIndexFn` to `virtualizer.scrollToIndex` so keyboard navigation reaches unmounted items.
See the virtualized examples for [Select](/docs/components/select#virtualized),
[Combobox](/docs/components/combobox#virtualized), [Listbox](/docs/components/listbox#virtualized), and
[Tree View](/docs/components/tree-view#virtualized).

### Web Components

The flavors are `<ark-list-virtualizer>`, `<ark-grid-virtualizer>` and `<ark-window-virtualizer>`. Options like `count`
and `estimated-size` are attributes. Items are stamped from a `<template>` and filled by `renderItem`:

```html
<ark-list-virtualizer count="10000" estimated-size="48">
  <ark-list-virtualizer-content>
    <template><ark-list-virtualizer-item></ark-list-virtualizer-item></template>
  </ark-list-virtualizer-content>
</ark-list-virtualizer>
```

```ts
const list = document.querySelector('ark-list-virtualizer')!
list.renderItem = (element, item) => {
  element.textContent = items[item.index]
}
```

Inside a collection component, compose with `as-child` and set `scrollToIndexFn` to
`({ index }) => list.virtualizer?.scrollToIndex(index)`.
