Ark UI queries the DOM through `document`, which points at the wrong place inside an iframe, Shadow DOM or Electron.
`EnvironmentProvider` tells components which root node and document to use.

## Setup

Wrap your components in `EnvironmentProvider`.

<ExampleCode id="setup" component="environment" />

### Usage in iframe

The provider detects the environment automatically. To set the `Document` yourself:

```jsx
import Frame, { FrameContextConsumer } from 'react-frame-component'
import { EnvironmentProvider } from '@ark-ui/react'

export const App = () => (
  <Frame title="IFrame Context">
    <FrameContextConsumer>
      {({ document }) => <EnvironmentProvider value={document}>{/* Your App */}</EnvironmentProvider>}
    </FrameContextConsumer>
  </Frame>
)
```

### Usage in Shadow DOM

Here's an example of how to set the `EnvironmentProvider`'s value with Shadow DOM in Solid.js `Portal` component.

```jsx
import { EnvironmentProvider } from '@ark-ui/react'
import { Index, Portal } from 'solid-js/web'

export const App = () => {
  let portalNode
  return (
    <Portal ref={portalNode} useShadow={true}>
      <EnvironmentProvider value={() => portalNode?.shadowRoot ?? document}>{/* Your App */}</EnvironmentProvider>
    </Portal>
  )
}
```

<FrameworkOnly framework="web">

### Web Components

`@ark-ui/web` has no `EnvironmentProvider`. Each element resolves its root node with `getRootNode()`, so components work
inside a shadow root without extra setup. Include your styles in that shadow root.

</FrameworkOnly>
