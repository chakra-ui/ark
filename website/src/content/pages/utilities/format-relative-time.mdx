## Usage

The relative time formatting logic is handled by the native `Intl.RelativeTimeFormat` API and smartly cached to avoid
performance issues when using the same locale and options.

```jsx
import { Format } from '@ark-ui/react'
```

<FrameworkOnly framework="web">

In `@ark-ui/web`, import `@ark-ui/web/format` to register the `<ark-format-relative-time>` element.

```html
<ark-format-relative-time value="2025-05-05" numeric="auto"></ark-format-relative-time>
```

Options are kebab-case attributes. The locale comes from the `locale` attribute, then the closest `lang`. Each element
also takes `value`, `locale`, and `options` as properties, for anything the attributes don't cover.

</FrameworkOnly>
