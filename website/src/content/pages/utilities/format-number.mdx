## Usage

The number formatting logic is handled by the native `Intl.NumberFormat` API and smartly cached to avoid performance
issues when using the same locale and options.

```jsx
import { Format } from '@ark-ui/react'
```

<FrameworkOnly framework="web">

In `@ark-ui/web`, import `@ark-ui/web/format` to register the `<ark-format-number>` element.

```html
<ark-format-number value="1234.45" style="currency" currency="EUR"></ark-format-number>
```

Options are kebab-case attributes. The locale comes from the `locale` attribute, then the closest `lang`. Each element
also takes `value`, `locale`, and `options` as properties, for anything the attributes don't cover.

</FrameworkOnly>
